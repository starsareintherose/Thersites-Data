# Landmark-based character optimization

## Merge different tps files to tnt

```bash
tnt run morpho.run,
```

This script align landmarks based on molecular phylogeny. 

## Visualize character optimization

In `gTNT`, type `p morpho.align.tnt` in command line to load the TPS file.

You can load the tree file using the command `p 00tre/<bi_ml.tre or eiw_iw.tre ew.tre>`.

Menu `Optimization` -> `Characters` `Map lanmarks...` to visualize the character optimization.
